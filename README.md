# EOBITCyberSecLab
Documentation and infrastructure for a five-node cybersecurity training lab at EOB.


EOB CyberSec Lab 

A hands-on cybersecurity laboratory built around five identical physical computers for offensive security, defensive security, virtualization, networking, digital forensics, and malware analysis.

Lab Hardware

The lab consists of 5 identical physical computers, each with 32 GB RAM.
