# Shop CyberSec Lab

A five-computer cybersecurity lab built for hands-on work with offensive security, defensive security, virtualization, networking, and malware analysis.

## Hardware

All five computers have 32 GB of RAM and are used for different parts of the lab.

| Computer | Role             | Hostname      |
| -------- | ---------------- | ------------- |
| 01       | Red Team         | `itredteam`  |
| 02       | Blue Team        | `itblueteam` |
| 03       | Proxmox          | `pve-01`      |
| 04       | Proxmox          | `pve-02`      |
| 05       | Malware Analysis | `itmalware`  |

## Network

The main lab network connects to the building network through a wall Ethernet port.

```text
Wall Port
    |
WAP / Router
    |
VLAN Router
    |
Switch
    |
    +-- Red Team
    +-- Blue Team
    +-- Proxmox 01
    +-- Proxmox 02
```

The VLAN router is used to separate the different parts of the lab.

The malware analysis computer is kept separate from this network.

## Red Team

**Hostname:** `itredteam`

The Red Team computer is used for offensive security testing against systems inside the lab.

Typical uses:

* Network scanning
* Vulnerability testing
* Web security testing
* CTFs
* Exploitation
* Packet analysis
* Security tool development

Common tools include Nmap, Wireshark, Burp Suite, Caido, Metasploit, Python, and Rust.

## Blue Team

**Hostname:** `itblueteam`

The Blue Team computer is used for defensive security work.

Typical uses:

* Log analysis
* Network monitoring
* Threat hunting
* Incident response
* Digital forensics
* Detection development
* Packet analysis

The Blue Team is intended to monitor activity generated by the rest of the lab.

## Proxmox

Two computers run Proxmox and provide most of the lab's virtual infrastructure.

### `pve-01`
Hostname (FQDN): cyssec4.lab.internal

Subnet Mask: 255.255.255.0

VLAN: 10.10.10.(100-199)

Gateway: 10.10.10.1

IP Addr: 10.10.10.100

Switch Port: 4


Used for general virtual machines and services.

Possible workloads:

* Windows machines
* Linux machines
* Active Directory
* DNS
* Vulnerable applications
* Test servers
* CTF targets

### `pve-02`
Hostname (FQDN): cyssec5.lab.internal

Subnet Mask: 255.255.255.0

VLAN: 10.10.10.(100-199)

Gateway: 10.10.10.1

IP Addr: 10.10.10.101

Switch Port: 5

Used for additional infrastructure and security services.

Possible workloads:

* SIEM
* Logging
* Monitoring
* Honeypots
* Security tools
* Additional test machines
* CTF infrastructure

The two Proxmox systems allow machines to be created, tested, reverted, and removed without affecting the physical workstations.

## Malware Analysis

**Hostname:** `itmalware`

The fifth computer is dedicated to malware analysis and reverse engineering.

It is separate from the main lab network.

Possible uses:

* Static analysis
* Dynamic analysis
* Reverse engineering
* Windows analysis VMs
* Linux analysis
* Network behavior analysis
* Digital forensics
* YARA
* Ghidra
* x64dbg

Malware analysis is performed only in the isolated environment. Malware samples are not stored in this repository.

## Lab Goals

* Learn offensive security
* Learn defensive security
* Practice networking
* Learn virtualization
* Build realistic attack and defense environments
* Practice incident response
* Learn malware analysis
* Experiment with different security tools
* Document projects and experiments

## Rules

This lab is for authorized cybersecurity testing and education.

* Only test systems you are authorized to test.
* Keep vulnerable systems isolated.
* Keep malware analysis isolated.
* Do not commit passwords, API keys, or other secrets.
* Do not upload malware samples to this repository.
* Document experiments and changes.
* Keep backups of important configurations.
